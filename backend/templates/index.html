Camera Input Specification & Capture Guide

instruction.md Aligned

This monocular 3D reconstruction pipeline expects a short RGB video of a static textured object captured while the camera moves in a smooth continuous arc around it. Results are generated in arbitrary relative coordinates.

Ideal Setup & Object
  • Centered Subject: Single static object centered in frame
  • Rich Texture: Visible edges, corners, wood grain, fabric, rough stone
  • Clean Scene: Clean table or indoor floor surface
  • Lighting: Soft but strong daylight or studio light (no extreme shadows)
Camera Orbit & Motion
  • Orbital Arc: Slow half-circle/arc around object (1–2m distance)
  • Smooth Continuous: Stable motion creating parallax without jerks
  • Specs: 720p or 1080p, 24–30 fps
  • Duration: 5–15 seconds optimal
Red Flags to Avoid
  • No Static Videos: Camera must move to recover 3D depth
  • No Mirrors / Glass: Breaks epipolar matching
  • No Fast Pans: Causes severe motion blur
  • No Plain White Walls: Needs visible feature corners
AI Video / Image Generation Prompt (From instruction.md Section 5)

"Generate a 10-second handheld smartphone video of a static textured object centered on a table in a well-lit indoor room. The camera slowly moves in a smooth arc around the object from 1 to 2 meters away, keeping the object centered in frame throughout. The object has rich visible features such as edges, corners, fabric texture, rough materials, wood grain, or patterned surfaces. No reflective glass, mirrors, plain white walls, or featureless surfaces. The motion is steady and continuous, with no sudden shakes, zooms, or blurry frames. Realistic lighting, 24–30 fps, 1080p quality, no people, no moving objects, suitable for monocular 3D reconstruction."
